# WindowsBaselineTestSimulator v1.0.0

Windows 11 「基线保护（Windows baseline protection）」8 项开机检测的**本地模拟器**。
用于在没装 Insider 预览版、`wldp.dll` 还没有 `Experimental_WldpQueryBaselineSecurityMode`
导出的机器上，先做应用集成、演示与自测。

> 不是安全边界。官方预览 API 本身也只允许用于遥测 / 审计 / 诊断 / 引导用户，不能作为拦截判据；
> 本项目同理，且它不修改任何真实安全设置。

## 8 项检测（与官方 criterion 一一对应）

| # | criterion | 中文 | 本机检测手段 |
|---|---|---|---|
| 1 | `..._TPM` | 安全处理器 | `Win32_Tpm.SpecVersion ≥ 2.0`（非提权 → `Unknown`） |
| 2 | `..._SECURE_BOOT` | 安全启动 | `SecureBoot\State\UEFISecureBootEnabled` |
| 3 | `..._VBS` | 基于虚拟化的安全 | `Win32_DeviceGuard.VirtualizationBasedSecurityStatus == 2` |
| 4 | `..._MEMORY_INTEGRITY` | 内存完整性 | `SecurityServicesRunning` 含 `2`（HVCI） |
| 5 | `..._SIGNED_DRIVERS_ONLY` | 仅签名驱动 | BCD `TESTSIGNING` / `NOINTEGRITYCHECKS` |
| 6 | `..._KERNEL_DEBUGGER_PROTECTION` | 内核调试器保护 | BCD `DEBUG` / `BOOTDEBUG` |
| 7 | `..._WHQL_ONLY` | 仅 Windows 认证驱动 | **代理**：已加载驱动的 `WinVerifyTrust`（内嵌签名 → `.cat` 目录签名 → 证书主题兜底） |
| 8 | `..._VULNERABLE_DRIVER_BLOCKLIST` | 易受攻击驱动阻止列表 | `CI\Config\VulnerableDriverBlocklistEnable` |

判定：全过才 `In`；任一项 `Off` 即 `NotIn`；有项读不到则 `Unknown`（绝不猜成 On）。

## 状态语义与官方一致

- **BootState（本次启动）** 来自「启动测量」快照，**只有它进总判定**；
- **CurrentState（下次启动）** 实时评估，只汇总成 `nextBootState`；
- 因此改任一项后 `state` 不变、`nextBootState` 变 —— 与官方「必须重启才生效」一致；
- `wbts apply` 就是模拟重启（冻结新的 BootState 并换 `bootId`）。

## 安装

**MSI（推荐，需要管理员）**

```powershell
msiexec /i WindowsBaselineTestSimulator-1.0.0-win-x64.msi
```

会安装到 `%ProgramFiles%\WindowsBaselineTestSimulator`、注册并启动服务 `WBTS`（LocalSystem、
自动启动）、创建开始菜单（打开面板 / 快速开关）与开机启动托盘快捷方式；卸载时先停服务再删除。

**免安装**

```powershell
.\WindowsBaselineTestSimulator.exe tray     # 托盘常驻，Ctrl+Alt+B 面板
.\wbts.exe status                           # 或 query（单行 JSON）
.\wbts.exe run                              # 前台跑管道服务（免安装验证）
```

## 快速开关

| 层级 | 触发 | 权限 |
|---|---|---|
| 软开关 | 托盘菜单「检测服务：开 / 关」、`Ctrl+Alt+D`、开始菜单快捷方式、`wbts toggle` / `enable` / `disable` | 不需要管理员 |
| 硬开关 | 托盘菜单「启动 / 停止 Windows 服务」弹 UAC，或 `wbts svc start\|stop\|restart\|status` | 需要管理员 |

关闭后不做任何评估（含驱动扫描），`query` 返回 `state:"Disabled"`、`detectionEnabled:false`。

## 命令行

```
WindowsBaselineTestSimulator.exe tray|panel|service|toggle|enable|disable
wbts.exe query [--human] | status | set <id> on|off|unknown|reset | reset | apply
wbts.exe whql <文件> | svc start|stop|restart|status | run | help
```

可用 id：`TPM` `SECURE_BOOT` `VBS` `MEMORY_INTEGRITY` `SIGNED_DRIVERS_ONLY`
`KERNEL_DEBUGGER_PROTECTION` `WHQL_ONLY` `VULNERABLE_DRIVER_BLOCKLIST`

## 给应用读的接口

命名管道 `\\.\pipe\WBTS.v1`，单行请求 → 单行响应；`query` 返回单行 JSON：

```json
{"schema":"WindowsBaselineTestSimulator/1","source":"service","detectionEnabled":true,
 "baselineVersion":1,"bootId":"…","state":"In","nextBootState":"In","criteriaReturned":8,
 "criteria":[{"criterion":"WLDP_BASELINE_SECURITY_CRITERION_TPM","id":"TPM",
              "bootState":"On","currentState":"On","simulated":false,…}]}
```

## 已知限制

- 第 7 项是代理口径（已加载驱动签名集合），不是微软的「策略 + 启动测量」。
- 非提权运行时第 1 项恒为 `Unknown`；装服务或以管理员 `run` 才可读。
- MSI 需要管理员安装；本版本自检覆盖数据库结构、`msiexec /a` 解包与文件哈希，
  未在非提权会话中端到端安装（会停在 1603）。
- 仅 Windows 10/11 x64。
